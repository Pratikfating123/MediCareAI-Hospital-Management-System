\# 🏥 MediCareAI - Hospital Management System



MediCareAI is a modern, full-stack Hospital Management System designed to simplify and digitize hospital operations. It provides a centralized platform for managing patients, doctors, appointments, medical records, and other healthcare workflows.



\## 🚀 Features



\* 🔐 Secure user authentication

\* 👨‍⚕️ Doctor management

\* 🧑‍🤝‍🧑 Patient management

\* 📅 Appointment scheduling and management

\* 📋 Medical record management

\* 📊 Dashboard and healthcare insights

\* 🏥 Hospital workflow management

\* 🤖 AI-powered healthcare assistance

\* 💾 Database management with Prisma ORM

\* 📱 Responsive and modern user interface

\## ⚙️ Installation



\### 1. Clone the repository



```bash

git clone https://github.com/Pratikfating123/MediCareAI-Hospital-Management-System.git

```



\### 2. Navigate to the project



```bash

cd MediCareAI-Hospital-Management-System

```



\### 3. Install dependencies



```bash

npm install

```



\### 4. Configure environment variables



Create a `.env` file in the project root and add the required configuration.



```env

DATABASE\_URL="your\_database\_url"

```



Never commit your `.env` file to GitHub.



\### 5. Setup Prisma



```bash

npx prisma generate

```



If database migration is required:



```bash

npx prisma migrate dev

```



\### 6. Start the development server



```bash

npm run dev

```



The application will be available at the local development URL shown in your terminal.
